# Задача: стартовый аудит una.md

## 1. Контекст
UNA.md — молдавская ERP/учётная система для НКО и малого бизнеса.
Гео: Республика Молдова. Языки: RU + RO. Аудитория: главные бухгалтеры, руководители НКО.
Это **первый** запуск по сайту — базовая точка отсчёта для всех дальнейших playbook'ов.

## 2. Что нужно сделать

### 2.1 Технический аудит (`mcp-crawler`)
1. Полный краул сайта (до 5000 URL). Собрать: коды ответа, редиректы, canonical, title/description, H1, глубину вложенности, orphan-страницы.
2. Проверить `robots.txt`, `sitemap.xml`, наличие `llms.txt`.
3. Core Web Vitals: полевые (CrUX) + лабораторные (Lighthouse) для 10 ключевых шаблонов страниц.
4. Валидировать структурированные данные. Ожидаемые типы: `Organization`, `SoftwareApplication`, `Article`, `FAQPage`, `BreadcrumbList`.
5. Проверить hreflang между RU- и RO-версиями, найти отсутствующие зеркала.

### 2.2 Аудит индексации и запросов (`mcp-gsc`, `mcp-ga4`)
1. Выгрузить запросы за 16 месяцев: показы, клики, CTR, средняя позиция.
2. Найти страницы с высокими показами и CTR ниже медианы (потенциал переписывания сниппетов).
3. Найти запросы на позициях 11–20 (быстрый рост при доработке).
4. Сверить: сколько страниц в sitemap vs в индексе; перечислить причины исключения.
5. GA4: органические сессии, конверсии, топ-страницы входа, отказы по шаблонам.

### 2.3 Контентный аудит
1. Инвентаризация всех контентных страниц: тема, интент, объём, дата обновления, целевой ключ.
2. Найти каннибализацию (несколько URL под один интент).
3. Найти устаревшее (не обновлялось > 18 мес. и теряет трафик).
4. Оценить E-E-A-T: есть ли авторы, экспертиза, источники, страницы About/Контакты/Юр. реквизиты.

### 2.4 Конкурентный анализ (`mcp-serp`)
1. По 20 базовым запросам снять ТОП-10 Google.md (RU и RO, desktop + mobile).
2. Выделить 5–8 постоянных конкурентов. Для каждого: домен, тип (вендор/каталог/медиа), сильные стороны.
3. Отметить наличие AI Overviews и кто в них цитируется.
4. Собрать People Also Ask по базовым запросам.

### 2.5 Ссылочный профиль (`mcp-backlinks`)
1. Ссылающиеся домены, динамика за 12 мес., анкор-лист.
2. Сравнение с конкурентами: разрыв по ссылающимся доменам.
3. Найти потенциально токсичные ссылки.
4. Найти незалинкованные упоминания бренда «UNA.md».

## 3. Ограничения
- Режим `dry-run`: **никаких изменений** на сайте и внешних площадках. Только чтение.
- Краул — не чаще 2 запросов/сек, уважать `robots.txt`.
- Не делать выводов о продукте, не подтверждённых содержимым сайта.
- Не оценивать «SEO-сложность» голословно — только с указанием источника данных.
