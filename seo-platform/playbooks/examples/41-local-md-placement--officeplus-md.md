# Задача: размещение на локальных площадках Молдовы (point.md, 999.md, каталоги)

## 1. Контекст
officeplus.md — интернет-магазин офисных товаров и оборудования, Кишинёв.
Сезон: конец августа — пик спроса «школа/офис». Аудитория: офис-менеджеры, закупщики, родители.
Tone of voice: практичный, без пафоса, с конкретикой (цены в MDL, наличие, доставка по РМ).

## 2. Входные данные
- Товарные категории с наибольшей маржой и наличием: см. `mcp-site` → `/api/categories`.
- Актуальные акции: `mcp-site` → `/api/promotions`.
- История прошлых размещений: `placements` (не повторять один и тот же текст — риск фильтра за дубли).

## 3. Что нужно сделать
1. **Аудит текущего присутствия.** Через `mcp-local-md` проверить существующие профили/объявления бренда на point.md, 999.md, makler.md, anuar.md. Зафиксировать: актуальность NAP (название/адрес/телефон), ссылки, описания.
2. **Исправление NAP-несоответствий.** Составить список расхождений — они вредят локальному SEO. Подготовить корректные версии.
3. **Подготовить 3 размещения:**
   - `point.md` — экспертный/новостной материал (не рекламный): «Как собрать офис к новому учебному году: чек-лист закупок» с органическим упоминанием бренда и 1–2 ссылками.
   - `999.md` — 5 товарных объявлений по топ-категориям: заголовок, описание, цена MDL, фото (взять из каталога через `mcp-site`), ключевые слова в RU и RO.
   - Каталоги (anuar.md / Yellow Pages) — выверенная карточка компании с полным NAP, категориями, часами работы, ссылкой.
4. **Все тексты — в двух языках** (RU + RO с корректной диакритикой, проверить через `mcp-lang`).
5. **Проверить правила площадки** перед подготовкой: лимиты частоты, требования к ссылкам, запрет на дубли. Если публикация через API невозможна — подготовить материал и пометить `manual_publish_required: true`.

## 4. Ограничения (Guardrails)
- **НЕ публиковать без Approve.** Все материалы складываются в `artifacts/posts/` и уходят в Approval Inbox.
- НЕ создавать фейковые аккаунты, НЕ обходить капчу, НЕ нарушать ToS площадок.
- НЕ размещать один и тот же текст на нескольких площадках — каждый текст уникален.
- НЕ указывать цены/наличие, которых нет в `mcp-site` (актуальность на момент запуска).
- НЕ более 5 объявлений на 999.md за один запуск (анти-спам лимит).
- Материал для point.md должен нести ценность читателю сам по себе — прямая реклама будет отклонена редакцией.
